# Notes App

[![Flutter](https://img.shields.io/badge/flutter-3.13-blue?logo=flutter)](https://flutter.dev)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

A **Flutter-based notebook-style note-taking application** that lets you create, edit, and organize notes with a clean, customizable interface. Perfect for jotting down thoughts, reminders, and daily logs with a classic notebook feel.

---

## Features

- Create and edit notes with a **rich-text editor**  
- **Auto-title generation** from the first line of content  
- **Customizable background colors** with automatic font color adjustment  
- Notebook-style lines for a classic writing experience  
- **Quick-save and auto-save** functionality  
- Pin notes to the top and **sort by date or color**  
- Secure your notes with **PIN or fingerprint lock**  
- Light and dark theme support  

---

## Getting Started

### Prerequisites

- Flutter SDK >= 3.x  
- Dart >= 3.x  
- A device or emulator to run the app  

### Installation:

1. Clone the repository:  
```bash
git clone https://github.com/<username>/flutter-notes-app.git
cd flutter-notes-app
```
### Install dependencies:
```bash
flutter pub get
```

### Run the app::
```bash
flutter run
```

## Usage

- Type your note content and the app automatically updates the title  
- Change the note’s background color using the color palette  
- Notes are saved automatically; you can pin or lock them for easy access and security
